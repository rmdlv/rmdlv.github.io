Exact values and other changes

Internal Sport target: 24.699997 → 33 km/h (+8.300003 km/h; +33.6%). The table uses the nominal stock speed of 25 km/h. Overspeed response threshold: ≈26.7 → 35 km/h (+8.3 km/h). Beep threshold: +5 km/h.

Command rise limit: 32,768 → 131,072 in Q16 (+98,304), or 0.5 → 2 internal units per control tick. A conversion to m/s² has not been established. The change applies only to positive, increasing drive commands in Sport, with neither braking nor regeneration active.

The active target filter coefficient depends on regulator state: 40–411 → 80–822 in Q16. Divide by 65,536 for dimensionless α: ≈0.000610–0.006271 → ≈0.001221–0.012543. Falling targets retain the stock filter.

Start0 removes the 3.2 km/h software floor in riding modes. Your existing start setting is preserved; this tool does not change it. Select 0 km/h separately in a compatible app to use zero start. Starting without a push is not guaranteed: the tested motor still needs a small push.

Speed overflow above ≈32.767 km/h is corrected: signed truncation is removed, and the display and distance counter read the speed magnitude as unsigned. The positive 16-bit field range changes from 32,767 → 65,535 thousandths of km/h (≈+100%). This is a numeric range, not a speed limit or a claim that the motor can reach 65 km/h.

A read-only build ID has been added to verify installation. The throttle filter, PI controller, current and temperature limits, braking and regeneration remain unchanged. Stock idle shutdown is retained. There are no bench motor-control commands in this build. BLE firmware is not changed.

Current and temperature limits, braking and regeneration are retained.

Warning and disclaimer

This is an experimental modification. Faster response and higher speed increase the risk of injury, overheating and scooter damage. Do not switch off the scooter or close this page during flashing. A failed update may require disassembly and recovery with an ST-Link.

Tested on one E2 Plus II. Matching model and firmware versions do not guarantee compatibility with every hardware revision. E2, E2 Plus and E2 Pro are not supported. Check throttle release and braking before riding. Follow local speed restrictions.
